## Featured Project

### [LogiClean](https://github.com/Aumar-mahmud/logiclean)

**Automated logistics ETL and data-quality pipeline**

LogiClean is a Python-based pipeline for cleaning, validating, and standardizing shipment and inventory data from CSV, Excel, and JSON files.

It can:

- detect shipment and inventory datasets
- normalize inconsistent column names and formats
- validate dates, quantities, statuses, SKUs, weights, and currencies
- detect and remove duplicate records
- flag records that require manual review
- generate cleaned Excel datasets
- generate repair reports with issue logs, rejected records, and a data-quality score

**Core technologies:** Python · Pandas · OpenPyXL · ETL · Data Validation · Supply Chain Data
