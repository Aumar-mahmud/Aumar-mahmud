### [LogiClean — Logistics ETL & Data Quality Pipeline](https://github.com/Aumar-mahmud/logiclean)

**Purpose**  
Turn inconsistent shipment and inventory files into standardized, analysis-ready datasets.

**What it handles**
- CSV, Excel, and JSON inputs
- shipment and inventory dataset detection
- inconsistent column-name mapping
- date, quantity, SKU, status, weight, city, and currency normalization
- duplicate detection and removal
- rejected-record handling and manual-review flags
- inventory stock classification
- issue tracking and data-quality reporting

**Outputs**
- `cleaned_data.xlsx` with standardized shipment and inventory data
- `repair_report.xlsx` with summary metrics, issue logs, rejected records, and an overall quality score

**Stack**  
Python · Pandas · OpenPyXL · ETL · Data Validation · Logistics Data
